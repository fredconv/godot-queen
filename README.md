# Dame de Pique

Jeu de cartes **Dame de pique** (Hearts) en Godot 4.7 — GL Compatibility.

**Type:** Jeu (Godot)  
**Statut:** active  
**Chemin canonique:** `projects/Games/DameDePique`

## Démarrage

1. Fermer toute instance Godot ouverte sur l’ancien chemin
2. Ouvrir **ce** dossier dans Godot 4.7 (`project.godot`)
3. Cursor : **File → Open Folder** sur ce chemin (ou le monorepo CreativeOS)

```bash
godot --path .
```
